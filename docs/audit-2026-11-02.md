The software is built and tested for a pilot. The pilot has not started, and several steps only Peter can take are overdue.

Of 172 requirements, 168 are built and tested, 2 are built with a stated limit and 2 are partly built by choice (170 of 172 counted as built). Practice and live match the code exactly.

Two things block progress:
1. Nobody can open the platform console. Both platform operators were removed on 13 Oct with the demo hotels, and no new one exists.
2. The 14 Oct dry run did not happen. Practice has no test hotel and no staff.

Neither is a code problem.
